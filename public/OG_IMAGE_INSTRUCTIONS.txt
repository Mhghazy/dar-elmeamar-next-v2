# Open Graph Image Placeholder

The static OG image for GitHub Pages has been generated and is ready for use.
Due to environment limitations, please ensure the following:

1. Copy the generated image from the workspace to:
   /public/opengraph-image.png

2. Delete the dynamic generator file at:
   /app/opengraph-image.tsx

These steps are required because GitHub Pages (static export) does not support
the dynamic ImageResponse feature used by Next.js in opengraph-image.tsx.
